# 布局条件适配与直接排序的实证比较：给定正确页面的文档证据区域排序

# 摘要

本文研究给定正确页面后的固定候选证据区域排序。冻结的视觉与问题编码器分别对整页图像和问题编码，得到图像 patch 表示 \(P\) 与问题 token 表示 \(Q\)；候选区域由解析器预先提供，任务不包含页面召回、任意框生成或答案生成。比较方法包括面积规则A、冻结空间传播B、普通patch适配器C、宽度变体C-wide、布局条件适配D及D-no-text；直接候选排序E作为原冻结实验之后的事后补充。C/D使用patch级正、负、忽略标签学习适配表示，E使用候选级标签直接学习候选分数；内部来源按协议划分训练、验证和开发角色，外部采用SciEGQA固定test的1623题、837页和1941个题—页单元。原冻结外部结果中，D-no-text的Top-1 Hit@0.5为30.80%，高于B的23.91%和C-wide的23.35%，两项校正配对区间均高于零；相对面积A低3.00个百分点，区间跨零，且Cov@5和Gold Recall@5均低于面积。E事后补充的Top-1为35.36%，但监督粒度和训练子集不同，不能据此宣称适配表示\(P'\)相对直接排序具有额外优势。结果显示，布局条件适配的收益依赖比较对象和评测目标，不能推出可靠超过面积、保持页面召回或改善完整系统性能。

**关键词：** 视觉文档检索；证据区域排序；布局条件适配；patch相关性；固定候选评测

# 1 引言

视觉文档检索需要同时处理页面外观、文字内容和空间结构。ColPali 以页面图像的多向量表示支持视觉文档检索，将问题 token 与图像 patch 的相关性保留到 late interaction 中[ColPali2025]。在此接口上，patch 相关性还可以借助坐标映射传播到 OCR 区域，形成页面内部的证据定位分数[Snappy2025]。RegionRAG 将区域作为检索增强生成的中间单位，MMDocIR 则区分页面级与布局级的多模态长文档检索任务[RegionRAG2025][MMDocIR2025]。这些工作共同表明，页面检索、页面内部区域定位和答案生成具有不同的输出粒度；布局条件表示也已成为文档理解中的常见建模路径[LayoutLMv32022]。

本文聚焦其中一个较窄且可控的问题：在已经给定正确页面的条件下，如何从解析器提供的固定候选区域中排序证据区域。给定页面后，候选集合已经确定，模型不负责重新召回页面、生成任意坐标框或生成答案。这样可以把页面级 MaxSim、patch 相关分数和候选区域分数分开考察，也可以避免把页面召回或生成器效果混入区域排序的比较。SciEGQA 提供了科学文档证据定位的外部评测背景，但本文只使用其给定正确页面后的候选排序部分，不把答案生成指标作为本文目标[SciEGQA2026]。

在这一任务边界内，直接使用冻结 patch 相关性进行空间传播并不等同于学习布局条件适配。本文因此比较一组具有明确接口差异的方法：面积规则 A 作为几何基线，冻结传播 B 作为 patch 到候选的空间参照，普通 patch 适配器 C 作为无布局输入的学习基线，布局条件适配 D 作为主要方法，并保留 C-wide、D-no-text 等变体以检查容量和输入因素。E 直接在原始 patch 表示上学习候选分数，作为原冻结实验之后加入的事后补充对照；它不被回写为原先同时预定的方法。

研究设计采用冻结的页面视觉与问题表示、共同候选集合和统一的区域指标。C/D 以patch级正、负、忽略标签训练适配表示，再用候选与patch的空间对应进行评分；E以候选级标签直接学习候选分数。外部结果分别报告 Top-1 首位命中、前五候选覆盖和多证据召回，并保留面积基线及不利结果。该设计的目标是描述不同读出与适配选择的实证边界，而不是构造一个声称全面优于基线的新检索系统。

本文的工作范围和贡献限于以下三点：

1. 实现一种在冻结视觉文档表示上加入文本、坐标和节点空间对应的布局条件适配，并明确其与普通patch适配及文本置零变体的接口差异。
2. 在给定正确页面和固定候选的统一协议下，建立面积、冻结传播、普通适配、布局适配与直接候选排序之间的具体方法对照，分开报告原冻结实验和E事后补充。
3. 报告布局适配在部分主指标比较中的收益及其边界，包括面积基线、直接排序和多证据覆盖所揭示的限制；不据此宣称可靠超过面积、保持页面召回或达到跨任务的最优性能。

# 2 相关工作

## 2.1 视觉文档多向量表示与区域相关性传播

视觉文档检索的一条重要路线是直接编码页面图像，并保留图像 patch 与问题 token 的多向量表示。ColPali 将页面图像映射为细粒度多向量，在 late interaction 中计算问题 token 与视觉 patch 的相关性，用于页面级文档检索和 ViDoRe 基准评估 [ColPali2025]。在本文的方法接口中，页级 MaxSim 是对每个问题 token 在全部页面 patch 上取最大相似度后求和；区域排序所需的 patch 相关分数则是对每个 patch 在问题 token 维度取最大值，随后才通过候选与 patch 的几何对应进行区域汇总。两种最大化方向不同，因此本文把页级分数、patch 分数和候选区域分数分别定义。

仅有 patch 相关性还不能直接产生结构化区域排序。Snappy 将视觉 patch 的相关性通过坐标映射传递到 OCR 区域，以空间交叠/IoU 权重汇总区域分数，并在推理阶段提供区域级检索 [Snappy2025]。本文的冻结传播 B 沿用这一类“patch 相关性—空间对应—候选区域评分”的基本关系：先按问题 token 得到 patch 分数，再以候选框和 patch 框的 IoU 做归一化加权平均。B 仅是本研究的冻结参照。由于本文没有完整复现 Snappy 的骨干、解析器、token 处理、候选筛选和系统协议，不能将 B 称为完整 Snappy 复现；同时，是否使用某种分位数筛选不能被单独写成本文 Top-1 差距的已证实原因。

上述路线主要回答“如何从视觉页面得到页面或区域相关性”。本文进一步把问题限定为给定正确页面后的固定候选排序：候选集合已由解析器提供，模型不重新生成页面、不动态合并 patch，也不承担答案生成。这样可以将比较对象限定为面积规则、冻结传播、普通 patch 适配、布局条件 patch 适配和一个直接候选排序对照，而不把页面召回或 RAG 生成收益混入区域排序结论。

## 2.2 布局条件融合与轻量适配

布局信息可以作为视觉和文本表示的联合条件。LayoutLMv3 通过统一文本/图像 masking 及 word-patch alignment 学习跨模态文档表示，面向表单、收据、文档视觉问答和布局分析等 Document AI 任务 [LayoutLMv32022]。这类工作说明坐标、图像 patch 与文本之间的对齐可以进入表示学习，但其目标是通用预训练或下游理解，不能直接替代本文的候选区域排序基线。

RegionRAG 则把布局和区域结构放到区域级 RAG 流程中：训练阶段使用区域级多模态对比监督，推理阶段将显著 patch 组织为语义区域，并把区域交给后续生成器 [RegionRAG2025]。它与本文的关系在于都关注页面内部证据，而差异在于任务链条和区域产生方式：RegionRAG 讨论动态区域提取、检索和生成，本文在正确页面与固定候选条件下学习 $P\rightarrow P'$ 或直接候选分数。本文使用的正/负/忽略 patch 标签和多正例损失是针对当前接口的监督迁移，不能将 RegionRAG 已有的监督思想包装为本文新创新。

本文的布局条件适配 D 采用页面节点的文本、类型、坐标和 patch—节点空间对应关系，对每个 patch 聚合局部节点信息，再通过残差 MLP 与 gate 修正原始 patch 表示。C 是不接收布局信息的平行适配对照，C-wide 只扩大普通适配器隐藏维度；D-no-text 则将文本输入置零而保留文本投影支路。因而本文比较的是在冻结视觉骨干和固定候选下，不同布局条件与适配位置的具体实现，而不是对通用 Document AI 预训练路线作性能宣称。登记参数量接近也不能消除监督粒度、训练子集和结构输入的差异。

## 2.3 区域排序与证据定位评测

MMDocIR 将多模态长文档检索拆分为 page-level retrieval 和更细粒度的 layout-level retrieval，布局对象包括段落、公式、图和表 [MMDocIR2025]。它为本文提供了任务背景和内部来源池，但本文按既定协议将 MMDocIR 的角色划为训练、验证和开发来源，source_dev 用于开发比较而非独立测试；本文也不把内部 benchmark 的页面检索数字与外部固定候选区域排序数字直接合并。

SciEGQA 以科学文档中的语义证据区域框标注建立证据定位与问答基准 [SciEGQA2026]。其人工 benchmark 为1623题，证据区域具有语义完整性，适合检验给定页面后的区域定位。本文使用其固定外部 test 的给定正确页面部分，并在该页面上对解析候选排序；不评估答案生成，也不把人工 gold 框数量、候选 Oracle 或问答准确率等同于本文的 Top-1 Hit@0.5、Cov@5 和 Gold Recall@5。

区域级 RAG 工作进一步提醒，固定候选排序、动态区域生成、页面检索和答案生成应分别报告。本文的 A/B/C/D/E 都输出既有候选的排序：A 按面积，B 传播 patch 相关性，C/D 先得到 patch 表示或分数再汇总候选，E 直接在冻结 $P$ 上学习候选分数。该设置不证明页面召回保持，也不证明候选生成、RAG 上下文压缩或答案质量提升。

综合来看，已有工作分别提供视觉多向量检索接口、patch 到区域的空间传播、布局条件表示、区域级 RAG 以及语义证据定位数据。本文的工作范围是受控实证比较：在冻结 ColPali、整页只编码一次、正确页面和共同候选条件下，观察具体布局适配相对普通适配和直接排序的表现边界。文献证据支持方法关系和任务区分，但本节不据此宣称首次、填补空白、SOTA 或已证明技术新颖性。

# 3 任务定义与方法

## 3.1 任务定义与表示

本文研究正确页面条件下的文档证据区域排序。给定问题 \(q\)、对应的证据页面 \(I\) 以及解析器生成的候选集合 \(\mathcal R=\{R_j\}_{j=1}^{M}\)，模型计算候选相关分数，并按分数降序输出排序。训练阶段还给定该问题在页面上的标注证据集合 \(\mathcal G=\{G_k\}_{k=1}^{K}\)。布局输入包含页面的完整候选节点，不依据当前问题或标注证据选择节点。该任务限于既有候选区域，不涉及从文档库召回页面、生成任意坐标框或生成答案。

冻结 ColPali 的视觉与问题编码部分，分别获得图像 patch 表示 \(P=[p_i]_{i=1}^{N}\in\mathbb R^{N\times d}\) 和问题 token 表示 \(Q=[q_t]_{t=1}^{T}\in\mathbb R^{T\times d}\)，其中 \(N=1024\)、\(d=128\)，\(T\) 为有效问题 token 数。局部区域评分只使用图像 patch，不使用页面表示中的提示 token。页面只进行一次整页视觉编码，后续适配与排序复用该表示，不对各候选分别进行视觉编码。

记 \(\nu(z)=z/\|z\|_2\) 为非零向量的逐行 \(\ell_2\) 归一化。问题评分前排除范数不超过 \(10^{-6}\) 的 token 行，再归一化保留行；该处理不依据语义类别删除有效 token。归一化相似度、页级 MaxSim 和 patch 相关分数分别定义为

\[
S_{ti}(P)=\nu(q_t)^\top\nu(p_i),
\tag{1}
\]
\[
u_{\mathrm{page}}(Q,P)=\sum_{t=1}^{T}\max_{1\le i\le N}S_{ti}(P),
\tag{2}
\]
\[
s_i(Q,P)=\max_{1\le t\le T}S_{ti}(P).
\tag{3}
\]

式（2）对每个问题 token 选择最相似 patch 后求和，输出一个页面分数；式（3）对每个 patch 选择最大的问题 token 相似度，输出 \(N\) 维分数向量。二者最大化方向不同，候选区域分数还需进一步汇总。使用适配表示时，以对应 \(P'\) 替换式（1）和式（3）中的 \(P\)。保持 patch 数与维度允许沿用原评分接口，但不构成页面召回性能保持的证据。

## 3.2 面积规则与冻结传播

面积规则 A 不使用问题或视觉表示，以页面坐标下的候选面积作为分数。对于 \(R_j=(x_{1j},y_{1j},x_{2j},y_{2j})\)，有

\[
r_j^A=\max(0,x_{2j}-x_{1j})\max(0,y_{2j}-y_{1j}).
\tag{4}
\]

冻结传播 B 将候选框与 patch 框映射到统一的模型坐标系，以二者的 IoU 汇总式（3）：

\[
a_{ji}=\operatorname{IoU}(R_j,B_i),\qquad
r_j^B=\frac{\sum_{i=1}^{N}a_{ji}s_i(Q,P)}
                 {\sum_{i=1}^{N}a_{ji}}.
\tag{5}
\]

式（5）为权重归一化的平均分数，不是未归一化累计分数。与全部 patch 的 IoU 权重均为零的候选赋分 \(-\infty\)。C 和 D 沿用此汇总方式，只替换 patch 表示。面积规则则保留为无需训练且不依赖问题的几何参照。

## 3.3 普通 patch 适配器及容量参照

普通适配器 C 对每个 patch 使用共享的残差网络。令 \(x_i=\nu(p_i)\)，则

\[
p'_{C,i}=\nu(x_i+f_C(x_i)),\qquad
f_C(x)=L_{2,C}\!\left(\operatorname{GELU}
         \left(L_{1,C}(\operatorname{LN}(x))\right)\right).
\tag{6}
\]

\(\operatorname{LN}\) 为 LayerNorm，两个带偏置线性层分别为 \(128\rightarrow256\) 和 \(256\rightarrow128\)。末层权重与偏置初始化为零，因此初始输出为原 patch 的归一化表示。适配器不输入问题、节点文本、坐标、类型或空间权重；问题在后续评分与训练损失中参与。

C-wide 保留式（6），将隐藏宽度由256扩大到1062。C/C-wide 与 D 是平行方案，均从原始 \(P\) 出发，C 不接在 D 后面。候选分数 \(r_j^C\) 由式（5）将 \(s_i(Q,P)\) 替换为 \(s_i(Q,P'_C)\) 得到。

## 3.4 布局条件 patch 适配

### 3.4.1 布局输入与空间权重

D 将页面候选区域表示为布局节点。第 \(j\) 个节点包含文本向量 \(e_j\in\mathbb R^{1024}\)、类型编号 \(z_j\) 和六维坐标

\[
c_j=(x_{1j},y_{1j},x_{2j},y_{2j},x_{2j}-x_{1j},y_{2j}-y_{1j}).
\tag{7}
\]

这里的边界框先映射并裁剪到 \(448\times448\) 模型坐标系，再除以448。训练来源的文本、标题及公式读取 text 字段，图像与表格读取 ocr_text 字段；外部节点使用解析器提供的 text 字段并记录来源。模块接收预先获得的文本向量，不在融合时重新编码文本。

记原始非负空间对应矩阵为 \(W_{\mathrm{raw}}=[w_{ij}]\in\mathbb R^{N\times M}\)，由页面框与 patch 网格的空间对应计算得到，不依赖问题或标注证据。对 patch 框 \(B_i\) 与布局节点框 \(R_j\)，本实现采用 patch 覆盖率

\[
w_{ij}=\frac{\operatorname{Area}(B_i\cap R_j)}{\operatorname{Area}(B_i)}.
\tag{8}
\]

框先按页面宽高分别缩放到 \(448\times448\) 模型坐标并裁剪到画布；退化节点返回全零行。D 使用其行归一化结果：

\[
\rho_i=\sum_{j=1}^{M}w_{ij},\qquad
\bar w_{ij}=
\begin{cases}
w_{ij}/\rho_i,&\rho_i>0,\\
0,&\rho_i=0.
\end{cases}
\tag{9}
\]

\(\rho_i\) 为原始空间权重累计量，不是去重后的联合面积覆盖率；重叠节点可使其大于1。\(W_{\mathrm{raw}}\) 与 \(W_{\mathrm{attn}}\) 用于布局融合或候选池化，\(A=[a_{ji}]\) 则专门用于式（5）的候选评分。本文明确区分这些矩阵的用途、归一化方向与索引。

### 3.4.2 节点编码

对每个坐标分量使用6个频率，得到72维编码。令 \(\omega_b=10000^{-b/6}\)，\(b=0,\ldots,5\)，则

\[
\phi(c_j)=\operatorname{Concat}_{a=1}^{6}
\left([\sin(c_{j,a}\omega_b)]_{b=0}^{5},
      [\cos(c_{j,a}\omega_b)]_{b=0}^{5}\right).
\tag{10}
\]

文本、位置与类型分别编码为128维，拼接后投影并归一化：

\[
h_j=\nu\!\left(L_{\mathrm{fuse}}
   [L_{\mathrm{text}}(e_j);
    L_{\mathrm{coord}}(\phi(c_j));
    E_{\mathrm{type}}(z_j)]\right).
\tag{11}
\]

分号表示拼接；三个线性投影的维度分别为 \(1024\rightarrow128\)、\(72\rightarrow128\)、\(384\rightarrow128\)。无效填充节点由掩码置零，并从注意力中排除。D 的未知类型编号0采用 embedding 的 padding 项。节点编码器与融合器可训练，预先提供的文本输入表示不在该模块内更新。

### 3.4.3 注意力、残差与 gate

对第 \(i\) 个 patch，按 \(\bar w_{ij}\) 降序选择最多4个有效且空间权重为正的节点，构成 \(\mathcal N_i\)。相等权重按原节点索引排序，节点输入按 layout_id 排序。对非空邻居集合计算

\[
\ell_{ij}=\frac{p_i^\top h_j}{\sqrt d}
                +\log(\bar w_{ij}+\varepsilon),\qquad
\alpha_{ij}=\frac{\exp(\ell_{ij})}
                 {\sum_{k\in\mathcal N_i}\exp(\ell_{ik})},
\quad j\in\mathcal N_i,
\tag{12}
\]

其中 \(\varepsilon=10^{-6}\)。注意力输入为原始 \(p_i\)，不额外替换为 C 中归一化的 \(x_i\)。节点经无偏置的 \(128\rightarrow128\) 值投影后汇总：

\[
\delta_i=\sum_{j\in\mathcal N_i}\alpha_{ij}L_{\mathrm{value}}(h_j).
\tag{13}
\]

残差网络与标量 gate 分别为

\[
f_D(\delta)=L_{2,D}\!\left(\operatorname{GELU}
                 (L_{1,D}(\operatorname{LN}(\delta)))\right),
\qquad
g_i=\sigma(L_{\mathrm{gate}}([p_i;\delta_i;\rho_i])).
\tag{14}
\]

其中 \(L_{1,D}:128\rightarrow256\)、\(L_{2,D}:256\rightarrow128\)，\(L_{\mathrm{gate}}:257\rightarrow1\)，\(\sigma\) 为 sigmoid。残差末层权重与偏置初始化为零；gate 权重为零、偏置为 \(-3\)。输出定义为

\[
p'_{D,i}=
\begin{cases}
\nu(p_i+g_i f_D(\delta_i)),&\mathcal N_i\neq\varnothing,\\
p_i,&\mathcal N_i=\varnothing.
\end{cases}
\tag{15}
\]

无有效邻居时直接保留原 patch。\(P'_D\) 只依赖页面及布局，不依赖当前问题；区域排序仍由 \(s_i(Q,P'_D)\) 经式（5）得到 \(r_j^D\)，因而使用问题信息。页面级组合接口保持图像 patch 数与维度，并将提示 token 按原值接回。

D-no-text 保留同一结构，仅将文本输入 \(e_j\) 置零。文本投影及其偏置仍存在，故该变体不是删除文本分支，零输入也不保证文本分支输出为零。坐标、类型、空间权重与节点掩码保持原输入。

## 3.5 事后补充候选排序对照 E

E 是原冻结实验之后引入的事后补充对照，保留原始 \(P\)，直接学习候选分数修正，不生成 \(P'\)。本文将其作为具体比较方案，不将普通 MLP 结构本身作为创新主张。

E 使用 \(W_{\mathrm{raw}}\) 的候选列权重池化视觉信息。对有效且 \(\mu_j=\sum_iw_{ij}>0\) 的候选，计算

\[
\tilde v_j=\frac{\sum_{i=1}^{N}w_{ij}p_i}{\mu_j},
\qquad v_j=\nu(\tilde v_j).
\tag{16}
\]

式（15）先对原始 \(P\) 加权平均，再归一化候选向量；不先逐 patch 归一化，也不使用 D 的行归一化 \(W_{\mathrm{attn}}\)。问题交互为

\[
x_{j,a}=\max_{1\le t\le T}[\nu(q_t)_a v_{j,a}],
\quad a=1,\ldots,d.
\tag{17}
\]

该操作按特征维度分别取最大值，输出 \(x_j\in\mathbb R^{128}\)，不是标准 MaxSim 的标量最大点积。布局分支将坐标投影与类型 embedding 相加：

\[
l_j=L_{\mathrm{coord},E}(\phi(c_j))+E_{\mathrm{type},E}(z_j).
\tag{18}
\]

位置投影为 \(72\rightarrow128\)，类型 embedding 包含6个编号，E 不使用节点文本。拼接 \(x_j,v_j,l_j\) 后，经 \(384\rightarrow680\rightarrow1\) 的 MLP 生成修正项；隐藏层使用 GELU：

\[
r_j^E=r_j^B+f_E([x_j;v_j;l_j]).
\tag{19}
\]

MLP 末层权重与偏置初始化为零，使初始分数等于 B。\(Q,P,v_j,x_j\) 为冻结特征，训练更新位置投影、类型 embedding 与分数 MLP。填充候选不参与排序；空间权重列和为零的候选不施加修正，保留 B 分数。

## 3.6 监督标签与训练目标

### 3.6.1 C/D 的 patch 级损失

C/C-wide 与 D/D-no-text 使用标注证据框构造 patch 标签。标注框映射并裁剪到模型坐标系后去除零面积框；patch 中心位于任一有效标注框内（含边界）者为正例 \(\mathcal I_+\)，与所有标注框交集面积均为零者为负例 \(\mathcal I_-\)，其余与证据相交但中心不在证据内者为忽略 \(\mathcal I_0\)。正例判定优先，三类互斥。

令 \(\hat s_i=s_i(Q,P')\)，则

\[
\mathcal L_{\mathrm{patch}}
=-\log\frac{\sum_{i\in\mathcal I_+}\exp(\hat s_i/\tau)}
                 {\sum_{i\in\mathcal I_+\cup\mathcal I_-}\exp(\hat s_i/\tau)},
\qquad \tau=0.25.
\tag{20}
\]

忽略 patch 不进入分子或分母。题—页单元必须同时提供正、负 patch 才可计算局部损失。式（19）直接优化 patch 分数，固定的 IoU 候选汇总不直接进入训练损失。

### 3.6.2 E 的候选级损失

E 按候选与标注证据的 IoU 构造标签：与任一标注框 IoU 不小于0.5者为正例，其余候选为负例。结合有效候选与非空空间权重条件，得到参与损失的正、负集合 \(\mathcal J_+,\mathcal J_-\)。损失使用最终候选分数：

\[
\mathcal L_{\mathrm{cand}}
=-\log\frac{\sum_{j\in\mathcal J_+}\exp(r_j^E/\tau)}
                 {\sum_{j\in\mathcal J_+\cup\mathcal J_-}\exp(r_j^E/\tau)},
\qquad \tau=0.25.
\tag{21}
\]

E 从满足原 D 训练条件的来源单元中进一步筛选训练单元：候选集合须有正、负例，且排除空空间权重候选后仍有正、负监督对象。参与损失的分数须有限，不满足训练条件的单元不用于更新。

两类损失均提高正例集合的总概率，不保证每个正例都取得高分。C/D 与 E 使用同来源标注，但监督粒度、标签构造和实际训练子集不同；接近的登记参数量也不等于有效容量完全匹配。因此，本比较不是仅改变表示修正位置的严格单因素实验。实际训练分母与配置在实验设置节报告。

# 4 实验设置

## 4.1 实验目标与评测范围

实验评估的是给定问题和正确页面后，从既有解析候选区域中排序证据区域的能力。所有训练方法共享冻结的 ColPali 视觉与问题表示、候选集合和区域评测脚本。实验不评估文档库页面召回、任意坐标框生成或答案生成；因此候选区域排序结果不能直接解释为页面召回保持或端到端检索收益。

## 4.2 数据角色与划分

内部数据沿用 `data-roles-v1` 和 `regions-v1` 的文档级角色划分。原始角色计数如下：`source_train` 为169篇文档、826题，`source_val` 为43篇文档、375题，`source_dev` 为91篇文档、412题，`quarantine` 为10篇文档、45题。MMDocIR 官方 evaluation 在本协议中重新划作 `source_train`、`source_val` 和 `source_dev` 来源池；`source_train` 用于构造监督并更新参数，`source_val` 仅用于早停和 checkpoint 选择，`source_dev` 用于冻结权重后的开发比较，不能称为最终独立测试。隔离角色不进入训练、验证或开发评测。

论文同时报告题数与题—页单元数。内部区域审计得到 train 1059、val 450、dev 545、quarantine 53 个单元；D/C 的实际训练只使用 `source_train` 中局部损失可用且未被页级重叠排除的1002个单元。checkpoint 选择使用 `source_val` 的374题、448个评测单元；因此“source_val 原始375题”与“实际用于选择的374题”不能混写。统一开发评测使用 `source_dev` 的412题、545个单元和91篇文档，其中包含无正 patch、无负 patch 或页重叠标记的评测单元；局部损失资格不等于评测资格。

E 从原 D 的1002个训练单元继续筛选，得到843个可训练且与 D 相交的单元，排除159个单元。其中117个没有负候选，42个没有 IoU≥0.5 的正候选；该筛选使用候选级标签，不能将843写成 D 的训练分母，也不能将 E 描述为同训练集复现。E 的 checkpoint 选择仍使用 `source_val` 的374题、448个单元，未使用 `source_dev`。

外部评测固定使用 SciEGQA-Bench 的 test revision `9bdca77be633cc3259d7e3739d35b38ab00bf5d9`，共1623题、837个唯一证据页、1941个题—页单元和9746个共同候选。外部候选由记录的 MinerU 4.0.10 Basic ONNX CPU 解析流程生成；内部训练侧候选的原解析版本与外部流程并未在本轮逐项复现，不能据此声称候选生成配置完全一致。外部 gold 只用于确定评测分母和计算指标，不进入向量生成、布局融合或候选排序。外部评测未静默删除异常题页，所有方法共享相同候选和分母。

## 4.3 候选、监督与过滤

页面 patch 表示固定为1024个图像 patch，提示 token 保留在页面缓存中但不参与局部区域评分。内部布局节点来自页面解析候选；D 的文本输入按节点类型取正文/公式的 `text` 或图像/表格的 `ocr_text`，缺失文本节点保留并以零向量进入文本投影。外部缓存记录837页的节点身份、形状和有限值检查通过，其中150个节点缺失文本但保留，9596个节点使用冻结的外部文本规则。

patch 级训练沿用第3节的正、负、忽略标签：patch 中心位于任一 gold 框内为正；与所有 gold 框零交集为负；其余边界 patch 忽略。无正 patch 或无负 patch 的单元不参与 C/D 局部损失，但仍可进入验证、开发或外部评测。E 使用候选级标签：候选与任一 gold 框的 IoU≥0.5 为正，其余有效候选为负；在排除空 (W_{\mathrm{raw}}) 候选后仍须同时保留正、负候选才可更新参数。两种监督粒度和过滤后的实际训练子集不同。

## 4.4 训练配置与权重选择

C、D 及 D 的开发变体均使用三个 seed（0、1、2），最多训练30个 epoch。已冻结配置使用 AdamW，学习率 $1\times10^{-3}$，weight decay 0.01，$\beta_1=0.9,\;\beta_2=0.999$，$\epsilon=10^{-8}$，每4个 unit 的损失取平均后更新，梯度范数裁剪上限为1.0，无 scheduler。温度 $\tau=0.25$。每个 seed 独立初始化；不加载 smoke、C 或旧融合权重。

每个 epoch 在 `source_val` 的全部448个评测单元上计算 Top-1 IoU≥0.5 主指标，严格提高时保存 checkpoint，平局保留较早 epoch，连续5个 epoch 未严格提高则早停。全部 seed 的 checkpoint 确定后才进行一次 `source_dev` 比较。C、D 及其变体的登记可训练参数分别为 C 66176、C-wide 273318、D 273410、D-no-text 273410、D-no-coord 273410；接近的登记参数量不代表有效容量严格匹配。

E 使用三个 seed，并按其冻结补充配置在 `source_val` 上选择 checkpoint；实际训练/最佳 epoch 分别为 seed0 的6/1、seed1 的7/2、seed2 的7/2。E 的登记可训练参数为272593。指定配置记录 E 使用 AdamW，学习率 `lr=0.001`，`weight_decay=0.01`，`betas=[0.9,0.999]`，`eps=1e-8`，`units_per_update=4`，`clip_max_norm=1.0`，且 `scheduler=null`。E 的候选级训练单元、模型结构和 checkpoint 选择分母仍与 C/D 不同。

## 4.5 指标与统计规则

主指标为 Top-1 IoU Hit@0.5：对同一问题的各证据页先取页内平均，再按问题宏平均。它衡量排序首个候选是否与任一 gold 框达到 IoU 0.5，不是页面召回率，也不是整题全部证据覆盖率。辅助指标包括 Cov@5（前五候选对 gold 并集的面积覆盖率）和 Gold Recall@5（IoU≥0.5 条件下前五候选对多个 gold 框的一对一召回率）。

训练方法的外部主指标先按题计算三个 seed 的逐题分数均值，再按文档聚类 bootstrap 2000次估计配对区间。seed 间标准差为样本标准差（ddof=1），单位为百分点；文档 bootstrap 区间描述固定模型下的文档抽样不确定性，未完整覆盖训练随机性。原冻结外部实验预先规定 D-no-text 与 A、B、C-wide 的三项主比较，并同时报告普通95%区间和 Bonferroni 校正后的98.333%区间。E 为事后补充，只报告 D-no-text−E 的唯一95%文档配对比较，不并入原三项比较族。所有差值沿用结果文件的精确值，不由舍入后的均值重新反算。

## 5.4 结果边界

原冻结外部实验支持的最窄表述是：在给定正确页面、共同候选和当前指标下，D-no-text 的 Top-1 点估计及预定区间高于 B 与 C-wide；相对面积 A 未建立可靠优势。E 事后补充提供了一个直接候选排序参照，但由于实验时序、监督粒度和训练子集不同，不能作为严格单因素机制实验。

# 6 讨论与局限

## 6.1 布局条件适配的收益边界

原冻结外部评测表明，D-no-text 的 Top-1 Hit@0.5 为30.7969%，高于冻结传播 B 的23.9063%和 C-wide 的23.3518%；相应的 Bonferroni 校正配对区间分别为 [+3.1573,+10.6887] 和 [+3.8736,+11.1144] 个百分点。该结果支持在当前正确页面和共同候选条件下，保留布局融合结构但将文本输入置零的具体变体，相对于这两个参照具有较稳定的主指标差异。D-no-text 相对面积基线 A 的差值为−2.9986个百分点，Bonferroni 区间为 [−7.8964,+1.8096]，因此不能据此声称可靠超过面积规则。开发集上相对面积的点估计也不能改变这一统计边界。

Top-5 指标进一步限定了结论范围。D-no-text 的 Cov@5 为58.5998%、Gold Recall@5 为54.3233%，均低于面积基线的64.1249%和57.0240%。因此，Top-1 的相对改善没有转化为对前五候选覆盖的全面改善。该差异说明单一首位命中与多证据覆盖衡量的是不同读出目标，不能用一个指标替代另一个指标。

## 6.2 与直接候选排序的关系

E 是原冻结评测之后加入的事后补充。它在原始 patch 表示上直接学习候选分数，外部 Top-1 为35.3563%，高于 D-no-text 的30.7969%；以 D-no-text−E 记录的唯一补充比较差值为−4.5595个百分点，95%文档配对区间为 [−6.7715,−2.4905]。这一结果说明，在本数据和本实现下，具体的直接候选排序方案构成了强对照，并不支持把从 $P$ 到 $P'$ 的布局适配解释为相对该方案具有额外优势。

该比较不能作为严格的单因素消融。E 使用候选级监督和843个筛选后的训练单元，D-no-text 使用patch级监督和1002个训练单元；两者的过滤条件、有效监督粒度和训练子集不同。两者登记参数量接近，也不足以证明有效容量严格匹配。E 属于事后补充，故其区间没有并入原冻结实验的三项 Bonferroni 比较族。

## 6.3 可能的解释与证据边界

一个合理但尚未验证的解释是，patch 级训练信号经过区域内平均汇总后可能被稀释，使局部高相关 patch 对候选排序的作用减弱。另一个假设是，固定的 patch 到候选读出方式限制了适配表示中可被评分函数利用的差异。上述说法只是待检验的机制假设；本轮没有进行替换汇聚函数、改变读出层或逐层归因的机制实验，不能把它们写成已证实原因。候选平均、patch 相关性和候选级分数的数值关系也不能单凭最终排名反推出因果机制。

## 6.4 局限

第一，外部评测只来自一个 SciEGQA 来源及其固定 test revision。内部训练、验证和开发角色与外部来源的候选解析流程并未逐项证明完全一致，候选生成差异可能影响跨来源比较。本文结果因此只适用于当前数据角色、候选集合和解析条件，不能推广为所有文档或候选生成器上的结论。

第二，C/D 的patch级损失与E的候选级损失对应不同监督粒度，且E的训练子集经过额外筛选；原冻结方法与事后补充方法不能视为完全匹配的容量或训练预算实验。三个seed的标准差反映训练随机性，文档bootstrap配对区间反映固定权重下的文档抽样不确定性，未覆盖所有训练和数据处理来源的不确定性。

第三，任务从正确页面开始，只对既有候选区域排序。外部记录登记了固定候选集合上的 Oracle 上限分析，用于说明候选集合本身的上限；本文没有据此完成候选生成器召回或完整任务链评估，也没有测量页面召回、答案生成质量或端到端系统成本。缓存评分时间和显存记录也不等于包含解析、编码和训练的完整部署成本。因此，当前结果不能推出页面召回保持、候选生成器性能、完整检索系统加速或问答质量提升。

# 7 结论

本文研究了给定正确页面后的固定候选区域排序问题，并在冻结视觉文档表示的条件下比较了面积规则、空间传播、普通patch适配和布局条件适配。原冻结外部结果显示，D-no-text 相对 B 和 C-wide 的 Top-1 Hit@0.5 差异得到预定区间支持；相对面积基线 A 的区间跨零，且其 Top-5 覆盖并未优于面积。因此，布局条件适配在当前协议下表现出有条件的收益边界，不能概括为可靠超过面积或改善所有证据覆盖目标。

E 是原冻结评测之后加入的直接候选排序补充。它的点估计高于 D-no-text，唯一补充配对区间也支持该具体比较方向，但E采用不同的候选级监督、训练子集和事后实验时序。因此，结果不支持将 $P'$ 表述为相对该直接排序方案具有额外优势，也不能推广到所有直接排序方法。全部结论限于正确页面和既有候选，不涉及页面召回、答案生成或完整系统成本。

后续工作可沿两个方向推进：其一，在保持候选和监督条件可比的前提下，设计针对patch到候选读出与汇聚方式的机制实验；其二，扩展到多来源候选生成和页面召回联合评测，以检验当前区域排序结论在更完整任务链中的适用范围。上述方向仍是待开展的研究，不构成本文已完成的方法或结果。
