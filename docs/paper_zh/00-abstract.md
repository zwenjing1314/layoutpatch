# 摘要

本文研究给定正确页面后的固定候选证据区域排序。页面由冻结视觉文档编码器生成问题与patch表示，候选区域由解析器预先提供，任务不包含页面召回、任意框生成或答案生成。比较方法包括面积规则A、冻结空间传播B、普通patch适配器C、宽度变体C-wide、布局条件适配D及D-no-text；直接候选排序E作为原冻结实验之后的事后补充。C/D使用patch级正、负、忽略标签学习适配表示，E使用候选级标签直接学习候选分数。内部来源按协议划分训练、验证和开发角色，外部采用SciEGQA固定test的1623题、837页和1941个题—页单元。原冻结外部结果中，D-no-text的Top-1 Hit@0.5为30.80%，高于B的23.91%和C-wide的23.35%，两项校正配对区间均高于零；相对面积A低3.00个百分点，区间跨零，且Cov@5和Gold Recall@5均低于面积。E事后补充的Top-1为35.36%，但监督粒度和训练子集不同，不能据此宣称适配表示$P'$相对直接排序具有额外优势。结果显示，布局条件适配的收益依赖比较对象和评测目标，不能推出可靠超过面积、保持页面召回或改善完整系统性能。

**关键词：** 视觉文档检索；证据区域排序；布局条件适配；patch相关性；固定候选评测
