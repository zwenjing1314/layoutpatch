# 研究简稿：布局条件的视觉文档证据定位——表示修正与直接排序的比较

日期：2026-10-12｜供导师讨论论文定位｜两页结构，非投稿终稿

## 第一页：研究问题与核心证据

**任务与方法。** 给定问题、正确页面及解析器生成的候选区域，输出候选区域排序；本研究不评测从文档库召回页面。冻结 ColPali，复用页面 patch 表示 P 与问题向量，通过布局节点、几何对应关系和局部可学习融合形成 P′，保持 patch 数与 MaxSim 接口，不裁剪页面、不重复视觉编码。原 D 引入文本；开发后选定的 D-no-text 去除节点文本。E 是冻结 P、池化候选视觉信息，并结合问题交互、坐标和类型直接学习候选分数的对照，不将其普通 MLP 结构视为新增创新。

**数据与统计。** 训练及选择权重使用 MMDocIR 来源的训练/验证划分，开发结果不作独立测试。外部 SciEGQA 固定为 80 篇文档、1623 题、837 页、1941 个题—页单元及9746个共同候选。主指标为 Top-1 IoU≥0.5 命中率，先题内页平均、再题宏平均；辅助指标为前五框去重覆盖率 Cov@5 和 Gold Recall@5。训练方法报告三个 seed 均值。

### 原冻结实验与事后补充结果


| 实验角色／方法         | Top-1（%） | Cov@5（%） | Gold Recall@5（%） |
| --------------- | -------- | -------- | ---------------- |
| 原冻结：A 面积降序      | 33.7954  | 64.1249  | 57.0240          |
| 原冻结：B 冻结传播      | 23.9063  | 60.1992  | 54.9908          |
| 原冻结：C 普通适配器     | 21.3802  | 51.4124  | 46.9398          |
| 原冻结：C-wide 容量对照 | 23.3518  | 50.5222  | 46.4161          |
| 原冻结：D 文本融合      | 21.9450  | 54.6627  | 51.2939          |
| 原冻结：D-no-text   | 30.7969  | 58.5998  | 54.3233          |
| 事后补充：E 直接排序     | 35.3563  | 61.5927  | 56.4387          |


**原预定比较。** D-no-text 相对 A、B、C-wide 的差值分别为 −2.9986、+6.8905、+7.4451 个百分点；三项 Bonferroni 校正区间分别为 [−7.8964, 1.8096]、[3.1573, 10.6887]、[3.8736, 11.1144]。支持优于 B/C-wide，但未可靠超过 A；跨零不表示等效或非劣。D-no-text 两项 Top-5 点估计均低于 A/B。

**E 事后补充（EXP-018）。** E−D-no-text 为 +4.5595 个百分点，唯一主要补充比较的95%文档配对区间为 [2.4905, 6.7715]；不并入原三项比较。E 三 seed 为33.0561%、32.3783%、40.6346%，样本标准差4.5837个百分点，不能只选最好 seed。E 两项 Top-5 高于 D-no-text、低于 A；E−A 仅有 +1.5609 个百分点数值优势，未建立可靠胜出。统计先平均三个 seed 的逐题分数，再按文档 bootstrap 2000次，区间不完整反映训练随机性。



## 第二页：论文主张与导师决策



### 已支持与尚不支持的结论

**已支持：** 实现并训练了真实 P→P′ 模块；在当前独立外部测试中，D-no-text 的 Top-1 优于 B 和近参数量 C-wide，因此单纯扩大普通适配器不是充分解释。E 补充结果支持这一具体直接排序方案优于 D-no-text，而非支持 P′ 的额外优势。开发消融未支持文本收益，显式坐标独立增益在多重校正后也未确立。

**不能成立：** 不能声称优于面积、全面改善 Top-5、P′ 优于直接排序、页面召回保持、完整系统效率更高或达到先进水平。B 不是完整 Snappy 复现；统计显著不等于技术新颖。外部有效邻居最多4个，TopK=4实际未截断邻居，不能将截断机制包装成已验证贡献。

**公平性边界。** E 使用272593个参数，但只是接近 D-no-text 登记参数量，并非有效容量严格匹配。D训练1002个单元，E候选级监督可用843个，排除117个无负候选及42个无正候选单元。两者同标注来源、不同监督粒度和实际训练子集；结果是具体方案比较，不能单独归因为“表示修正位置”。外部结果已用于提出E，本补充必须保留事后属性。

### 暂定贡献与论文定位

暂定题目采用本文标题，定位为**布局条件适配的受控实证比较**，而不是“提出更优定位算法”。可陈述三项工作：①实现冻结视觉主干、接口兼容的布局适配方案；②在共同候选与评测条件下，比较几何、冻结传播、适配器、布局融合和直接排序；③报告布局适配相对普通适配器的收益，以及面积规则、直接排序和多证据覆盖揭示的适用边界。这些是工作与证据贡献，技术新颖性仍待相关工作论证。
