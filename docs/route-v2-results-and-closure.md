# Route-v2 结果与实验闭合

> 证据：`@runs/retrieval/route_v2_external_eval_v1/20261009_163938/`。任务是给定正确页后的候选区域定位，不是端到端页面检索。

## 外部结果与预定比较

主指标为 Top-1 IoU Hit@0.5；其余两列是必须同时披露的 Top-5 指标。

| 方法 | Top-1 | Cov@5 | Gold Recall@5 |
|---|---:|---:|---:|
| A 面积 | 33.7954% | 64.1249% | 57.0240% |
| B 冻结传播 | 23.9063% | 60.1992% | 54.9908% |
| C PatchAdapter | 21.3802% | 51.4124% | 46.9398% |
| C-wide | 23.3518% | 50.5222% | 46.4161% |
| D | 21.9450% | 54.6627% | 51.2939% |
| D-no-text | 30.7969% | 58.5998% | 54.3233% |

预定主比较（百分点）：D-no-text−A = −2.9986，Bonferroni 校正区间 `[-7.8964, 1.8096]`；D-no-text−B = +6.8905，`[3.1573, 10.6887]`；D-no-text−C-wide = +7.4451，`[3.8736, 11.1144]`。对 A 的区间跨零，不表示等效或非劣；对 B、C-wide 的区间为正，支持独立 Top-1 收益。B 仅是冻结传播对照，不是 Snappy 完整复现。

## 可直接用于论文的结果分析

在冻结 ColPali、保持 patch 数和 MaxSim 接口、不裁剪且不重复视觉编码的条件下，开发集选定的 D-no-text 在冻结 SciEGQA 外部测试上取得 30.80% Top-1，较冻结传播 B 和近参数量 C-wide 分别提高 6.89、7.45 个百分点，校正区间均为正。这表明收益不能仅由扩大普通适配器容量解释，并支持布局条件可学习模块整体具有外部定位效用。然而，D-no-text 仍低于面积基线 A 约 3.00 个百分点，差值区间跨零；其 Cov@5 与 Gold Recall@5 也低于 A、B。因此结论限于 Top-1 排序改善，不能写成超过面积规则、全面改善 Top-5、统计等效或页面检索能力保持。

## 开发结果与外部结果

开发集用于模型选择和归因，不能称独立测试：D−C-wide 的校正区间为正；去文本优于 D；D−D-no-coord 的多重校正区间跨零。外部集只验证冻结后的泛化：D-no-text 相对 C-wide、B 的 Top-1 优势成立。两类证据共同支持“模块整体有效”，但没有证明文本有益，也没有把显式坐标、W、邻域或空间偏置中的某一项单独确认为有效机制；统计显著性也不等于方法新颖性。

## 主张—证据—局限—缺口

| 主张 | 已有证据 | 必须承认的局限 | 硬缺口 |
|---|---|---|---|
| 真实网络修改 | 可学习 P→P′，冻结主干，三 seed 训练并外评 | 只评正确页定位 | 无 |
| 独立 Top-1 收益 | 对 B/C-wide 校正区间为正 | 未胜 A | 无 |

| 布局机制归因 | D-no-text 外部有效；开发消融齐 | 只能归因整体，不能锁定具体空间机制 | 无 |
| 面积基线 | A 完整保留且数值最高 | D-no-text−A 跨零 | 无 |

## 结束判定

A 类（结果正确性阻塞）与 B 类（支撑上述受限主张必须补齐的证据）均不存在，**既定实验结束，进入写作**。旧 `PAPER_SPEC`/`THESIS_SPEC` 的页面非劣、完整效率表、噪声与更多消融属于历史路线愿望或更宽论文主张；它们与现行正确页定位范围冲突时，不追溯为本轮必做实验。C 类未来扩展可包括端到端页面召回、完整成本核算和更细空间机制消融。真正剩余事项只有写作：按上述边界完成结果、讨论和相关工作，保留负结果与所有强基线。
