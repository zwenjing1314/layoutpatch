# 区域标注协议 region-ann-v1

生效日期：2026-09-30。替代 v0 的选择口径及人工流程；不修改候选、划分、评测指标、权重或历史标签，不批准训练。v0 和 2026-09-29 方案保留为历史记录。

## 实验目标和标签边界

PAPER_SPEC 5.7 要求独立训练区域监督；2026-09-29-region-annotation-plan.md 第3.4/6节使用多正框排序。因而本协议采用“全量直接证据候选”，不是“只选一个最小充分证据集合”，也不是“所有主题相关区域”。

这些是人工判断的候选相关性标签，不是精确 gold 坐标，也不是官方 Area 软标签 y(c)。不能声称二者等价。后续训练方案需如实注明二值/多正例监督；本协议不能保证 dev 指标提升。

## 逐框选择的唯一口径

对本题每个候选框逐一检查：它是否包含可在页面上核实、直接支持回答的文字、图表事实、数值或必要关联信息？是则选入 chosen_box_ids。

- 每个独立充分的证据框都选，不能因另一框更短、更小或更直接而漏选。
- 联合才能支持回答的证据框全部选。只包含背景知识、相同关键词、主题相关内容的框不选。
- 问题提到“这幅图”不自动要求选图；图中须有与回答有关的可核实视觉事实。图注可独立支持时选图注，但还须检查其他候选是否也直接支持答案。
- 大框若包含直接证据也选，在备注记录过粗或冗余；不能为躲避面积捷径而删掉真实正例。类型 image/text 不决定正负。
- 嵌套/重叠框若确实都包含直接证据，均为正例。框大小不是标签标准。
- 全部候选审阅后仍有无法判定的候选，整题保留 pending，备注列出疑问，不将其自动当负例。

## 字段操作定义

- chosen_box_ids：全部已确认的直接证据框，整数列表，编号沿用原候选。
- cover_levels：可选对象；full=该框单独足以支持回答；partial=包含直接证据但单独不足。只允许已选框的字符串编号键，如 {"5":"full"}。不理解时留 {}；不可理解为数值面积比例。
- cover_ok：所有已选框合起来足以支持回答为 true，否则 false。
- no_candidate：没有任何候选包含可确认的直接证据时才为 true。若有部分证据但整体不足，保留所选框、cover_ok=false、no_candidate=false；此类题不进当前训练分母。
- cross_box：cover_ok=true 且没有任何单框足以支持回答、必须联合多个已选框时为 true。多个框各自独立充分时为 false。cover_ok=false 的已判断题填 false，在备注解释证据不完整。pending 填 null。
- label_status：审阅完成且有证据框为 labeled；确认没有证据候选为 skipped；不确定为 pending。labeled 不自动意味着可进训练。
- skipped：chosen_box_ids=[]、cover_levels={}、cover_ok=false、no_candidate=true、cross_box=false。
- pending：chosen_box_ids=[]、cover_levels={}、cover_ok/no_candidate/cross_box=null、labeled_at=null，remark 记录原因。
- remark：本轮模型辅助标注每题写短句，记录证据位置、选择理由、歧义/粗框；不得复制未经核实的模型陈述。
- annotator：真实人工身份 A/B。protocol_version=region-ann-v1；sample_id 保持 ann-xxxx，不加序号装饰。labeled_at 由工具记录实际 UTC 时间。

cross_box 是当前集合充分性的摘要，不能描述所有替代证据组合。必要时在 remark 写明组合。后续损失不得强制某一独立充分框高于另一个独立充分框。

## 两位人工分别使用模型辅助

A 可参考 DeepSeek，B 可参考 Gemini；使用相同规则和同一问题、原图、叠图，不提供预选框。两人提交前互不查看对方结果或模型回复。模型用于翻译及证据建议，人工须核对原文/图形和编号；无法核实保持 pending。

每位标注者另外保存原始模型回复、提示词、题号、服务/显示模型名称（未显示则注明）、日期、复问记录及人工改动。原始记录与最终 JSONL 分开保存。不同辅助模型不等于消除相关错误，模型一致不等于正确。

ann-0004 已在共同对话中讨论，登记为校准题，不进入盲标一致率分母；其他已共同讨论的题同样登记。不能自动填入该题标签。此前“只选5”只是最小集合口径判断，不作为 v1 答案；需重新检查0等替代直接证据。

一致性在裁定前按两位人工原始结果计算：报告校准/待定/可比较题数，非空集合 Jaccard；两人均无候选的题另报，不以空集合满分抬高 Jaccard；单方无候选且另一方有框计 Jaccard=0。no_candidate 一致率另报。保留分歧，第三人复核；无第三人则如实记录双人协商。裁定后的一致不能作为独立一致率。

原 pilot 阈值仅为内部质检门槛，不能当作正确率证明；不得混用旧口径结果。论文应报告实际流程、辅助模型、人工职责、样本数、分歧和限制。正式训练前仍需人工质量复核。

## 版本迁移和操作

v0 标签不得自动改版本。先导出备份；v1 工作簿拒绝导入旧版本文件，需两人各自按新口径重新审阅并填写。保存新导出为独立 v1 文件；不要覆盖 v0。

打开 pilot_materials/workbook.html。导出文件名含 v1。校验示例：

`uv run python scripts/region_ann_pilot.py check --annotator A --labels experiments/region_annotation/labels_annotator_A_v1.jsonl`

只处理 train_fit pilot；不读 dev_eval/test_eval 或 evaluation gold；不重画框、不训练。未选框仅在全量审阅且无未决歧义的最终标签中才可作为负例候选，进入训练前须独立完成数据质检。
