# EXP-003 BGE-M3 dense 页级 baseline（正式）

## 1. 实验目的

- 一句话：补齐小论文执行规范 `docs/PAPER_SPEC.md` 第 7.2 节 Phase 1A 四基准中的文本 dense 一项，用真 BAAI/bge-m3 给出可信页级分。
- Gate 归属：迁移批次清单 `docs/MIGRATION_BATCHES.md` 批次 3（Phase 1A）；EXP-001 ColPali 分母已冻结，本实验只补对照。

## 2. 环境

- uv `.venv`（唯一运行时），CPU 检索（BGE-M3 编码走 CPU，未用 GPU）
- 模型缓存：系统全局缓存 `C:/Users/WenJing/.cache/huggingface/hub/models--BAAI--bge-m3`（由旧仓库 `mmdoc-evidence-rag/artifacts/hf_cache/hub/models--BAAI--bge-m3` 经 robocopy 复制；旧仓保持只读）；`local_files_only=True` 可加载，维度 1024，`max_seq_length=8192`
- 编码耗时：约 13.4 分钟（804.9s，313 文档逐文档编码）

## 3. 数据和 split

- 数据集：`mmdocir_evaluation` 全量，无 split
- 规模：313 documents、20395 pages、170338 nodes、1658 queries
- 预测 30112 hits（= 1658 query × top_k 20，文档内检索按页数封顶后总量与 EXP-001 一致量级）

## 10. 结果解释

- 支持假设：文本 dense 可用，但页级弱于 ColPali（R@5 0.7750 vs 0.8390，差约 6.4 个点），说明纯文本向量在版式文档上不如视觉 late-interaction。
- A/B/C/D：不适用（页级对照；区域诊断以 EXP-002 的 ColPali Top-5 为分母）。
- 与上一版对比：首次 BGE-M3 真模型全量（旧 TF-IDF 降级分数作废，不可引用）。
