# EXP-006 Phase 1C 三无训练基线：1343 matched A 选框 + 45 B 消解（正式）

## 1. 实验目的

- 一句话：用冻结 ColPali 向量测三类无训练基线能走多远，给 1C 生死判交决策材料。小论文执行规范 `docs/PAPER_SPEC.md` 第 7.4 节要求四条线，本实验一次跑完其中的三类新基线（Snappy 式传播 max/mean/iou、固定聚合 coverage/iou_mass、动态显著分组 P25/P50/P75），原始 ColPali 页检索分母沿用 EXP-001。
- Gate 归属：迁移批次清单 `docs/MIGRATION_BATCHES.md` 批次 5；判定数字口径按大论文规范 `docs/THESIS_SPEC.md` 第 11.2 节（B 占比≥10% 且 Snappy 最好聚合消掉≤50% 才进 Phase 2），不满足转第 11.3 节有序收缩。

## 2. 环境

- uv `.venv` + `--extra colpali`（query 文本塔 GPU 编码，batch 隐式单条；页向量全部走 `artifacts/colpali` 缓存，0 次额外视觉编码）
- 缓存布局断言：每页 `(1031, 128)` = `[7 prefix, 1024 patches]`（prefix-first，`patch_scores_from_vectors` 取后 1024 行；形状不符直接抛错，不静默）
- query 编码是 EXP-001 同模型 `vidore/colpali` 文本塔；gold 只用于打分，不参与选框
- 全量耗时 225.3 秒（约 3.8 分钟，1388 题逐题 query 编码 + MaxSim + 七档选框）

## 3. 数据和 split

- 数据集：`mmdocir_evaluation` 全量，无 split；K=5，IoU 阈值 0.5（与 EXP-002/EXP-005 同口径）
- 评估集（严格口径）：
  - A：1343 题 = 页命中 + matched + Top-K 内最优 IoU≥0.5（EXP-005 的 matched A 全集）
  - B：45 题 = 页命中 + Top-K 内最优 IoU<0.5（严格 B；注意 unmapped 页命中为 47=45B+2A 纯 unmapped 命中 `mmdocir_00520/00672`，本实验分母用 45 而非 47，已在 JSON 的 `meta.note` 写死）
- 选框页：Top-K 内 rank 最小的 gold 页（确定性）；gold 框取该页第一行 gold bbox

## 10. 结果解释

- A 选框：固定候选 Top-1 准确率最高 0.3187（fixed:iou_mass），Snappy-iou 0.2621 次之，max/mean 仅 ~0.10，动态分组 ≤0.1035。说明"候选里有框"≠"能排第一"：EXP-005 候选召回上限 100%（matched A 定义），排序选框上限仅 ~32%。这是批次 5 测到的真实排序能力，与 EXP-005"候选召回上限非排序能力"声明一致。
- B 消解：Snappy/固定五档 0/45 = 0.0，符合"框缺失消不掉"预期（EXP-005：B=45/45 unmapped_only，可寻址 0.0）；group 三档 0.6889/0.3556/0.0889 为自组框碰大框虚高，不计入消解率（阈值越松框越大越易碰中，P25→P75 单调降即证据）。
- 1C 判定（按 11.2）：B 占比 3.24%（<10%）且可寻址 0.0；Snappy 最好消解 0/45 = 0%（≤50% 条满足但第一条不满足）→ 不进 Phase 2，转 11.3 有序收缩。建议 B2 失败分类学（45 B 全 unmapped_only + oracle 58 缺框）+ B1 效率对比（ColPali/Hybrid/BGE 同表已有），B3 跨页表格需另立项。
- 与上一版对比：首次 1C 实测（此前只有 EXP-005 的预期"消解率≈0"）。
